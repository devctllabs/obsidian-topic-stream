## Agent skills

### Issue tracker

Issues and specs are tracked as Markdown files under `.scratch/<feature>/`. See `docs/agents/issue-tracker.md`.

### Domain docs

Domain documentation uses the single-context layout. See `docs/agents/domain.md`.

### Storybook

Product stories render production components and the same connected screen composition as the plugin. Mock external services and data at their ports. The primary Shell story includes every currently implemented screen and action; extend it with each feature. Keep harness-only probes hidden from the catalog. Multilingual demo content uses English and Spanish.
